1. 회원가입 시 인증번호 문자가 도착하지 않는 핵심 원인

빗썸에 휴대폰 번호를 입력하고 [인증번호 전송]을 눌렀는데도 3분 타이머가 끝날 때까지 SMS 문자가 오지 않는 경우가 있습니다. 십중팔구 통신사 자동 스팸 필터링 부가서비스 때문입니다.

2. 통신사별 스팸 차단 해제 3단계

통신사 스팸 필터링 앱 확인법

  • SKT (T스팸필터): 앱 실행 ➔ 스팸 메시지함 ➔ 발신번호 1661-5551 또는 02-1588 차단 해제.

  • LG U+ (U+ 스팸차단): 차단 설정 ➔ 국번/키워드 차단에서 '거래소', '인증' 키워드 예외 등록.

3. 문자가 계속 안 올 때 10초 만에 뚫는 '카카오 간편가입'

통신사 문제로 SMS 수신이 계속 지연된다면, 굳이 문자를 기다릴 필요 없이 '카카오 계정으로 시작하기'를 이용하면 휴대폰 문자 인증 절차 없이 10초 만에 가입이 완료됩니다.
